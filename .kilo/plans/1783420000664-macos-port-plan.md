# План: портирование EnRu на macOS (darwin)

## Контекст

EnRu — глобальный переключатель раскладки по клику левого/правого Ctrl. Сейчас поддерживаются только Windows (`for_windows.go`, `//go:build windows`) и Linux (`for_linux.go` + `x11record.go`, `//go:build linux`). macOS не реализована: нет `for_darwin.go`, поэтому `main.go` ссылается на нереализованные функции (`resolveExe`, `printVersionInfo`, `installAutostart`, `removeAutostart`, `startBackground`, `startConsole`, `printUsage`) и сборка под `GOOS=darwin` падает. Linux-зависимости (`grafov/evdev`, `godbus/dbus`, `x/sys/unix` inotify, cgo на `-lX11 -lXtst`) и Windows-зависимости (`jxeng/shortcut`, `go-ole`) на macOS не применимы.

Цель: добавить полноценную поддержку macOS без регрессий для Windows/Linux.

## Принятые проектные решения

1. **Переключение раскладки** — cgo + приватный `TISetCurrentKeyboardLayoutInputSource` через `dlopen`/`dlsym` из фреймворка HIToolbox (подход утилит `macism`/`issw`). Перечисление источников через публичные `TISCreateInputSourceList` + `TISGetInputSourceProperty(kTISPropertyInputSourceID)`. Идентификаторы: `com.apple.keylayout.US`, `com.apple.keylayout.Russian`.
2. **Перехват клавиш** — cgo: `CGEventTapCreate(kCGSessionEventTap, kCGHeadInsertEventTap, kCGEventTapOptionListenOnly, mask KeyDown|KeyUp, callback)` + `CFRunLoop` в горутине. macOS-коды: Left Ctrl = 59, Right Ctrl = 62. Логика «клик Ctrl» — state machine down/up как в `for_linux.go` (`listenKeyboards`).
3. **Beep** — переиспользовать `generateWAV` (общий с Linux) и проигрывать через `afplay <wav>` (аналог `paplay`/`aplay`). Fallback `fmt.Print("\a")`.
4. **Автозапуск** — LaunchAgent: `~/Library/LaunchAgents/github.abakum.EnRu.plist` (`RunAtLoad=true`, `ProgramArguments = <exe> start`).
5. **Фоновый режим** — `exec.Command(exe, "console")` с `syscall.SysProcAttr{Setsid: true}` (darwin поддерживает), без перенаправления stdio (как в Linux).
6. **Сборка** — `CGO_ENABLED=1 GOOS=darwin`, cgo LDFLAGS: `-framework ApplicationServices -framework CoreFoundation` (ApplicationServices включает Carbon/HIToolbox и CoreGraphics для CGEventTap).

## Out of scope

- VNC-спецслучай «активен вьювер → форсировать English». Его нет в Go-версиях ни для Windows, ни для Linux (только в `EnRu.ahk`). Отложить.
- Universal binary (Intel+Apple Silicon) — по умолчанию собирается под нативную arch хоста; universal — опционально, отдельным пунктом.
- Иконка в menu bar/tray (macOS использует статус-айкон, а не tray Windows) — не входит в текущий контракт `main.go`.

## Задачи

1. **Вынести общую часть `generateWAV`/`sin`** из `for_linux.go` в новый `cmd/EnRu/beep_common.go` **без build-tag** (чистый Go, без Linux-зависимостей). Убрать эти функции из `for_linux.go`. Это позволит переиспользовать их в `for_darwin.go` без дублирования.
   - Проверить, что `for_linux.go` после переноса компилируется (другие Linux-функции остаются).

2. **Создать `cmd/EnRu/for_darwin.go`** (`//go:build darwin`):
   - `resolveExe()` — копия Linux-версии (`os.Executable` + `EvalSymlinks` + fallback).
   - `printVersionInfo()` — `runtime.GOOS+"/"+runtime.GOARCH`.
   - `playBeep(freq)` — `generateWAVFile` + `afplay <wav>`; fallback `\a`.
   - `startConsole(ctx)` — определить коды Left/Right Ctrl (59/62), `signal.Notify(SIGINT, SIGTERM)`, вызвать слушатель событий.
   - `listenKeyboards`-аналог для macOS: цикл приёма событий из канала `CGEventTap` + state machine down/up (как Linux), вызов `switchLayout(0|1)` + `playBeep`.
   - `installAutostart()` / `removeAutostart()` — создание/удаление LaunchAgent plist.
   - `startBackground()` — `exec.Command(exe, "console")` + `Setsid`.
   - `printUsage()` — текст как в Linux, с путём `~/Library/LaunchAgents`.

3. **Создать `cmd/EnRu/darwin_eventtap.go`** (`//go:build darwin`):
   - cgo-блок: `#cgo LDFLAGS: -framework CoreGraphics -framework CoreFoundation`, включить `<CoreGraphics/CGEvent.h>`, `<CoreFoundation/CFRunLoop.h>`.
   - `goExport` callback (через `//export`), принимающий keycode + pressed, кладущий `message`-событие в глобальный канал (как `xrecordKeyCallback`).
   - `listenCGEventTap(ctx, inbox)`: создать tap, проверить ошибку (нет прав Accessibility → понятный лог с инструкцией добавить процесс в System Settings → Privacy & Security → Accessibility), запустить `CFRunLoop`, на `ctx.Done()` — `CFRunLoopStop`.

4. **Создать `cmd/EnRu/darwin_tis.go`** (`//go:build darwin`):
   - cgo-блок: `#cgo LDFLAGS: -framework ApplicationServices`, включить `<Carbon/Carbon.h>` (HIToolbox).
   - `switchLayout(group uint) error`: через `dlopen(".../HIToolbox.framework/HIToolbox")` получить `TISCreateInputSourceList`, `TISGetInputSourceProperty`, `TISetCurrentKeyboardLayoutInputSource`. Перечислить источники, сопоставить по `kTISPropertyInputSourceID` с `com.apple.keylayout.US`/`com.apple.keylayout.Russian`, вызвать `TISetCurrentKeyboardLayoutInputSource`. Вернуть ошибку, если источник не найден (пользователь не добавил русскую раскладку в System Settings).
   - Кэшировать `TISInputSourceRef` по group после первого успеха (как `switchLayoutFunc` в Linux).

5. **Обновить `Makefile`**:
   - Добавить цель `darwin`: `GOOS=darwin CGO_ENABLED=1 go $(BUILD) -o "$(PROGRAM_NAME)-darwin" ./cmd/EnRu/`.
   - Добавить `darwin-install`.
   - Включить `darwin` в `all` и `install`.
   - Обновить `clean` (добавить `EnRu-darwin`).
   - `.PHONY` дополнить `darwin darwin-install`.

6. **Обновить `README.md`**: добавить строку про поддержку macOS, требования (оба Input Source добавлены, разрешение Accessibility, Xcode Command Line Tools, Go).

## Валидация

**На Mac (основная):**
- `GOOS=darwin go build ./cmd/EnRu` — компилируется без ошибок.
- `make darwin` — собирается бинарь.
- Запуск `./EnRu-darwin console`:
  - При первом запуске — корректный лог про необходимость Accessibility; после добавления в System Settings → Privacy & Security → Accessibility — события ловятся.
  - Клик левого Ctrl → переключение на US + beep (1046 Гц).
  - Клик правого Ctrl → переключение на Russian + beep (523 Гц).
  - Логи: `→ English` / `→ Русский` (как в Linux).
- `./EnRu-darwin install` → файл создан в `~/Library/LaunchAgents/`, `./EnRu-darwin uninstall` → удалён.
- `./EnRu-darwin stop` → корректно убивает фоновый процесс.
- Проверка edge-case: русская раскладка НЕ добавлена в Input Sources → `switchLayout(1)` возвращает понятную ошибку, не падает.

**На Linux (регрессия, здесь и сейчас):**
- `GOOS=linux CGO_ENABLED=1 go build ./cmd/EnRu` — без изменений.
- `GOOS=windows CGO_ENABLED=0 go build ./cmd/EnRu` — без изменений.
- Убедиться, что вынос `generateWAV`/`sin` в `beep_common.go` не сломал Linux-сборку.

## Риски

- **Accessibility permission**: CGEventTap не создастся без гранта. Mitigation — понятный лог-инструкция при ошибке `CGEventTapCreate`.
- **Приватный `TISetCurrentKeyboardLayoutInputSource`**: может быть удалён в будущей macOS. Mitigation — `dlsym` с проверкой `nil` + явная ошибка; документировать в README зависимость от приватного API.
- **Отсутствие русской раскладки** в System Settings → переключение невозможно. Mitigation — graceful error, не crash.
- **CGEventTap в фоне (Setsid)**: без GUI/сессии tap может не работать под LaunchAgent, запускаемым до логина или в агентском контексте. Mitigation — проверить запуск через LaunchAgent; если не ловит — запускать как пользовательский процесс в сессии (`LimitLoadToSessionType=Aqua`).

## Открытые вопросы (после базовой реализации)

- Нужен ли universal binary (Intel + Apple Silicon)? Решается опциональной целью `darwin-universal` (`GOARCH=arm64` + `GOARCH=amd64` + `lipo`).
- Минимальная версия macOS для подтверждения — тестировать на текущем macOS хоста, документировать как минимум.
